# perf-research/ideas/

Each file here tracks one experiment from the `perf-ideas.md` hopper.

## Naming
`NNN-<short-kebab-name>.md` matching the idea number in `perf-ideas.md`.

## Lifecycle
1. **Not started** — file may not exist yet. Create from `TEMPLATE.md` when you pick up the idea.
2. **In progress** — fill the *Baseline* and *Experiment Log* sections as you cycle.
3. **Done** — fill *Final Verdict*, update `../STATUS.md`, and optionally delete the worktree.

## Template
See [`TEMPLATE.md`](TEMPLATE.md) for the full structure.
